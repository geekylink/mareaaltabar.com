Data export and import

Download a table as CSV, edit it in a spreadsheet, then upload it back. The file keeps the same columns as the export. Import is all-or-nothing: if any row is invalid, nothing changes.

Import updates rows by id (or slug, for categories and sections) and creates rows with a blank id. It never deletes: removing a row from the file leaves it in the database. Use the panel for deletions. Every change is written to the audit log.
